      What is running here

        What YouPI accepts

          Gmail authorization is still missing.
          1. Create or choose a Google Cloud project and enable the Gmail API.
          2. Configure the OAuth consent screen, then add the scopes gmail.readonly and userinfo.email.
          3. Create an OAuth Web application client. Its redirect URI must be the YouPI public host + /oauth/callback (use http://localhost:6003/oauth/callback only while local).
          4. In the YouPI Merchant Admin → Gmail Direct API, enter the client ID/secret and use its Connect button. Sign in with the Gmail account that receives the bank alerts.
          5. Confirm a real bank credit alert arrives in that inbox from a bank domain. FamPay's own sender domain is rejected as INVALID_EMAIL_DOMAIN.
          This console cannot open Google consent because no Gmail connector or refresh token is available to it. Gmail is supporting evidence, never proof of money.
