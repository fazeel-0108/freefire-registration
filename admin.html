Organiser sign in

Sign in with your own organiser ID and personal PIN. The PIN is verified on the server, nothing is stored in this page, and the same account works from your phone, a tablet or a laptop.

Use the recovery key instead

A break-glass Super Admin credential for when no PIN works. Anyone with it gets full access, so retire it once every organiser has an account: delete the admin_key Script Property.

No account yet? In the Apps Script editor run setupSuperAdmin() once. It prints an organiser ID and a strong PIN for the first Super Admin, and that PIN is never stored or shown again. There is no default PIN, and no administrator credential in this page or the repository.
